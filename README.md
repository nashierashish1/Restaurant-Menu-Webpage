# 🍴 Restaurant Menu Webpage

A simple and interactive restaurant menu webpage built using **HTML**, **CSS**, and **JavaScript**.  
This webpage allows users to view different menu categories such as Starters, Main Course, Desserts, and Drinks — all on one smooth, responsive page.

---

## 🌟 Features
- Clean and modern design  
- Category buttons for menu navigation  
- Responsive layout for mobile and desktop  
- Simple animations for better user experience

## 🛠️ Technologies Used
- HTML 
- CSS  
- JavaScript
